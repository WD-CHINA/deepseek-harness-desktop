# Release guide

Release builds are created on native GitHub-hosted runners:

- macOS arm64: `macos-15`
- macOS x64: `macos-15-intel`
- Windows x64: `windows-latest`

Pull requests and main-branch pushes run unsigned unpacked packaging checks.
Unsigned manual builds publish prerelease tags such as
`v0.0.2-unsigned.42`. Signed releases are started manually with an existing
stable `v<version>` tag and publish the resulting DMG, ZIP, and NSIS installer
to GitHub Releases.

## Required signing credentials

Trusted certificates cannot be generated by this repository. Add these values
under **Settings → Secrets and variables → Actions** before running the signed
release workflow.

### macOS

- `MAC_CSC_LINK`: base64-encoded Developer ID Application `.p12`
- `MAC_CSC_KEY_PASSWORD`: password used when exporting the `.p12`
- `APPLE_API_KEY`: base64-encoded App Store Connect `.p8` API key
- `APPLE_API_KEY_ID`: App Store Connect API key ID
- `APPLE_API_ISSUER`: App Store Connect issuer ID
- `APPLE_TEAM_ID`: Apple Developer team ID

### Windows

- `WIN_CSC_LINK`: base64-encoded Authenticode `.pfx`
- `WIN_CSC_KEY_PASSWORD`: `.pfx` password

The release workflow deliberately fails when a required secret is absent. It
also passes `forceCodeSigning=true`, so an unsigned public release cannot be
created silently.

## Publish the package version

```bash
npm ci
npm run verify
app_version="$(node -p "require('./package.json').version")"
git tag "v$app_version"
git push origin "v$app_version"
```

The tag must exactly match `v` plus the version from `package.json`. Then open
**Actions → Release → Run workflow** and enter that existing tag. Unsigned
prerelease tags must never be used for this workflow.

## Post-build verification

macOS:

```bash
codesign --verify --deep --strict --verbose=2 "DeepSeek Harness Desktop.app"
spctl --assess --verbose --type exec "DeepSeek Harness Desktop.app"
xcrun stapler validate "DeepSeek Harness Desktop.app"
```

Windows PowerShell:

```powershell
Get-AuthenticodeSignature ".\DeepSeek Harness Desktop-<version>-win-x64.exe"
```

Install each artifact and confirm that opening and closing the app leaves no
Harness, terminal, or PowerShell child processes behind.
