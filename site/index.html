BUILT-IN WORKBENCH

侧边栏工作台，开箱即用。

首次启动自动安装 Better Sidebar 插件，为 Harness 带来文件管理、终端、Git 等完整开发工具。

📁

文件管理

懒加载目录树 + CodeMirror 编辑器，支持图片、Markdown、HTML 内联预览。

💻

终端

xterm.js + node-pty 真实 shell，断线重连回放。

🌳

Git 面板

真 diff + VSCode 式 diff tab，暂存、提交、一键还原。

🌐

内嵌浏览器

多开网页 tab，沙箱 iframe 隔离，外链默认在侧边栏打开。

🧩

后台任务

subagent 拓扑 + 后台任务监控，实时输出与强制终止。

🪟

双工作台

右侧栏 + 底部面板，拖拽拆分合并分栏，会话级布局持久化。

COMMAND LINE

命令行插件管理。

桌面应用本身即 DSH CLI 代理。内置 Node + pnpm，无需全局安装任何工具即可管理插件。

Terminal
$ dsh-desktop plugin add dsh-remote-web-ui@1.0.0
正在安装插件: dsh-remote-web-ui@1.0.0
[plugin-installer] dsh-remote-web-ui@1.0.0 安装完成
插件安装成功: dsh-remote-web-ui@1.0.0
$ dsh-desktop plugin list

📦 plugin add

安装插件到桌面版 web profile，自动处理原生构建和兼容性。

📋 plugin list

列出当前已安装的所有插件及其版本。

🗑 plugin remove

卸载插件并执行兼容性清理。
